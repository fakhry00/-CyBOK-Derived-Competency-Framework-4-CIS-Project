# CyBOK-Derived Competency Framework and Teaching Materials for Security-Informed Software Engineering

This repository supports the development of a CyBOK-derived competency framework
and associated teaching materials for Security-Informed Software Engineering education.

The project aims to translate relevant knowledge areas from the
Cyber Security Body of Knowledge (CyBOK) into practical competencies,
learning outcomes, teaching activities, assessment approaches, and
hands-on learning resources.

## Project Scope

The current work focuses on:

- CyBOK evidence extraction and analysis
- Identification of relevant cybersecurity competencies
- Mapping CyBOK knowledge to competency-based learning outcomes
- Secure software engineering and DevSecOps practices
- CI/CD-integrated security controls and automated security gates
- Development of teaching activities, practical exercises, and assessment approaches
- Creation of reusable teaching and technical resources

## Current Development

The project is being developed iteratively through several phases:

1. **CyBOK Evidence Extraction**
   - Identification of relevant concepts and practices from selected CyBOK Knowledge Areas.

2. **Competency Framework Development**
   - Translation of CyBOK evidence into structured competencies.

3. **Curriculum Mapping**
   - Mapping competencies to learning outcomes, teaching activities, and assessment.

4. **Teaching and Technical Resources**
   - Development of practical exercises, CI/CD security gate examples, teaching materials, and supporting technical resources.

## Expected Outputs

The project is expected to produce:

- A CyBOK-derived competency framework
- Learning outcome and curriculum mappings
- Teaching materials and practical exercises
- CI/CD security gate examples and templates
- Assessment guidance
- Supporting resources for adoption and delivery
